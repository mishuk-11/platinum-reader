1. Install

The installer. It asks whether to install just for you (no admin rights) or for all users in Program Files (admin).

From a terminal (one line)

Windows (PowerShell):
irm https://raw.githubusercontent.com/mishuk-11/platinum-reader/main/install.ps1 | iex

Linux / macOS:
curl -fsSL https://raw.githubusercontent.com/mishuk-11/platinum-reader/main/install.sh | sh

Both download the newest release from GitHub and check its SHA-256 checksum before installing. Silent installs: setup.exe /S /CurrentUser or setup.exe /S /AllUsers. All commands are in install-commands.txt.

Make it your default reader

Settings → Make Platinum Reader the default… opens Windows’ Default apps page. Choose Platinum Reader for each file type. Windows 11 only lets you pick defaults; once you do, files show Platinum Reader’s minimal type icons (PDF, EPUB, MD, …).

2. Getting started

Home: open a document, drop files anywhere, or reopen a recent one at the page where you stopped.

  • Open: Ctrl+O, the Open button, drag and drop, or double-click a file in Explorer.
  • Recent: every document reopens at your last page. Press and hold a recent item for 3 s to preview its first page.
  • Tabs come back: open tabs are restored the next time you start (Settings → Reading).

4. Find

Every match is highlighted; the current one is orange. The counter shows “1 / 720”.

  • Ctrl+F opens the bar. Enter / Shift+Enter or the arrows move between matches.
  • Aa turns on match case.
  • Highlights from Find are temporary and disappear when you close the bar.

5. Highlights, unhighlight and saving

Select text and a floating menu appears: 6 highlight colors, the eraser, copy, web search, Ask AI, Translate and Define.

Highlights in yellow and green. The blue dot on the tab means “not saved into the file yet”.

  • Highlight: select text, pick a color.
  • Unhighlight: select highlighted text and click the eraser. It also removes highlights already saved inside the PDF. You can also click a highlight to remove it.
  • Save (Ctrl+S): writes your highlights into the PDF as real highlight annotations, so other PDF readers show them too.
  • Save as (Ctrl+Shift+S): writes a new PDF and keeps the original untouched.
  • Closing a tab or the window with unsaved changes asks: Save, Don’t save or Cancel.
Only PDFs can be saved. In EPUB, MOBI, comics and other formats your highlights are kept by Platinum Reader itself.

6. Tabs, split view and windows

Right-click a tab for more options.

Split view: two documents side by side, each with its own zoom and page. Drag the divider to resize.

  • Open in new window moves a tab into its own window.
  • Duplicate, Copy path, Show in folder, Close others.
  • Drag tabs to reorder. Middle-click closes. Ctrl+Tab switches, Ctrl+1…9 jumps.
  • Settings → Layout → Tab bar position: Left gives vertical tabs.

7. Hold to preview

In File Explorer: press and hold a PDF for 3 seconds without moving, and its first page appears. Let go and it’s gone.

  • Works in File Explorer, on the desktop, and inside the app (tabs, Recent, History).
  • It runs in the background: the reader doesn’t need to be open. A tiny helper starts when you sign in.
  • Turn it off in Settings → Reading. The helper stops within 5 seconds and no longer starts at sign-in.
  • Keep the mouse still: moving more than a few pixels is a drag, just like in Explorer.

8. Settings

Settings (Ctrl+,).

  • Appearance: light / dark / system, 8 accent themes (Platinum, Graphite, Ocean, Forest, Rose, Amber, Violet, Sepia), dark pages for night reading, density.
  • Layout: tabs on top or left, toolbar labels, outline sidebar.
  • Reading: default view and zoom, page gap, reopen tabs, hold to preview, default app.
  • Web: which AI and search engine the selection menu uses.
  • Updates, Extensions and Developer sections.

9. Help, self-test and feedback

⋮ → Help, or F1.

The self-test checks the engine, search, storage, installation, default app, the background helper and the update server.

Send feedback: pick a topic, write a message, optionally attach the diagnostic report and a screenshot.

  • Send with Gmail opens Gmail in your browser, addressed to the developer with the subject “Needs Pt. Reader: <topic>”. Use my email app uses your installed mail program.
  • Attachments are saved to a folder that opens next to the email. Drag them into the message.
  • The diagnostic report contains versions, settings and self-test results, never your documents’ contents.

10. Updates

  • Platinum Reader checks GitHub Releases at launch and once a day, and always asks first.
  • Update now downloads, verifies the SHA-256 checksum and runs the installer. Or Download installer, or Copy terminal command.
  • Pause with Remind me in 7 days, Skip this version, or turn automatic checks off in Settings → Updates.

11. Extensions and developer mode

  • Built-in extensions: Translate, Dictionary, Word count, Reading progress. Switch them in ⋮ → Extensions.
  • Add your own .js extension to add selection buttons, menu items and document hooks. See EXTENSIONS.md.
  • Settings → Developer mode: performance overlay, text-layer view, render quality, parallel renders, DevTools, diagnostics, reset.

13. Troubleshooting

ProblemFix
Files show a blank iconChoose Platinum Reader as the default for that type (Settings → Make Platinum Reader the default…). Windows 11 only shows an app’s icons for types you assigned to it.
Hold to preview does nothingRun the self-test (F1). “Hold to preview in Explorer” should pass. Keep the mouse completely still for 3 s. Search results and some cloud folders aren’t supported.
Send with Gmail shows a login pageSign in to Gmail in your browser, or use “Use my email app”.
Update check says “not published yet”Normal until the first public release is on GitHub.
Something elseF1 → Report a problem. It includes everything the developer needs.
